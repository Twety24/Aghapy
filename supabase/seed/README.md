# Daily verse dataset

The daily verse bank includes the Arabic Smith–Van Dyck (1865) public-domain text for Psalms, alongside the initial curated verse entries.

- Source: https://github.com/midvash/bible-data
- Version: Arabic Smith–Van Dyck (SVD), Psalms book JSON
- License: Public domain, as declared by the dataset source.
- Imported rows: 2,461 Psalm verses.
- Database table: `public.daily_verse_library`

The database stores the daily selection separately in `public.daily_verses`, and each member's saved verses in `public.daily_verse_saves`.
